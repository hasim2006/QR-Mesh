# Optical vs Acoustic Air-Gap Comparison

| Dimension | QRMesh (Optical) | SoundMesh (Acoustic) |
| :--- | :--- | :--- |
| Physical Medium | Screen Photons / Light | Sound Frequencies (Speaker/Mic) |
| Data Bandwidth | High (1 KB – 50 KB files) | Moderate (short text / tokens) |
| Line-of-Sight | Required | Not required (omindirectional sound) |
| Ambient Noise | Immune to audio noise | Sensitive to acoustic background |
